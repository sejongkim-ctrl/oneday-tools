# 하루 하나 도구

하루에 하나씩 만드는 작은 브라우저 도구 모음. 서버, 빌드, 가입, API 키가 없다. `index.html`을 열면 동작한다. 폰에서는 https://sejongkim-ctrl.github.io/oneday-tools/ 로 연다.

| 날짜 | 도구 | 하는 일 |
|---|---|---|
| 2026-09-23 | [사진 위치정보 지우개](exif-cleaner/) | 사진의 GPS·촬영일시·기기 정보를 지운다 |

## 규칙

도구 하나는 폴더 하나다. 기능도 하나다. 만들면 `index.html` 목록에 한 줄을 추가한다.

파일을 다루는 도구는 전부 브라우저 안에서 처리한다. 업로드하지 않는 데 그치지 않고, CSP `default-src 'none'; connect-src 'none'`으로 외부 통신 자체를 막는다. 배포본은 `build.mjs`로 만든 HTML 한 장이다. 더블클릭(file://)으로 열리지 않는 구조는 쓰지 않는다.
