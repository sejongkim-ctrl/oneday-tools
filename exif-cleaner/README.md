# 사진 위치정보 지우개

사진에 남은 촬영 위치(GPS), 촬영 일시, 기기 정보를 지우는 브라우저 도구. 파일은 기기 밖으로 나가지 않는다. 서버도 빌드도 없이 `index.html`을 열면 끝난다.

## 왜 만들었나

스마트폰 사진에는 찍은 좌표가 같이 저장된다. 블로그나 중고거래에 집에서 찍은 사진을 올리면 집 위치가 같이 올라간다. 네이버·인스타그램은 업로드할 때 이 정보를 지우지만, 카카오톡 원본 전송이나 이메일 첨부, 파일 공유는 그대로 남는다.

## 구조

| 파일 | 책임 |
|---|---|
| `js/exif.js` | JPEG 구간·PNG 청크를 훑어 GPS·촬영일시·기기·회전 정보를 읽는다 |
| `js/strip.js` | 메타데이터 바이트만 들어내고, 회전 정보가 있으면 픽셀에 구워 넣는다 |
| `js/app.js` | 파일 입력, 전후 비교 표시, 내려받기 |

## 화질을 지키는 방식

JPEG는 다시 압축하지 않는다. Exif(APP1), Photoshop IPTC(APP13), 주석(COM) 구간만 잘라내고 픽셀 데이터는 원본 그대로 옮긴다. 색 프로파일(ICC)은 남긴다. 지우면 색이 틀어지기 때문이다.

예외는 회전 정보가 있는 사진이다. 회전 값까지 지우면 사진이 눕거나 뒤집혀 보인다. 이 경우에만 회전을 픽셀에 적용해 다시 저장한다(품질 0.95).

## 검증

GPS 좌표와 회전 값이 든 JPEG, 텍스트가 든 PNG를 만들어 헤드리스 브라우저로 처리한 뒤 결과 파일을 다시 열어 확인했다.

| 입력 | 결과 |
|---|---|
| GPS·기기 정보 JPEG | Exif 태그 6개 → 0개, GPS 제거, 픽셀 차이 0 |
| 회전 값 6인 JPEG | 보이는 방향과 결과가 일치(300x400), 최대 픽셀 차이 10(재압축) |
| 텍스트 청크 PNG | 텍스트 제거, 픽셀 차이 0 |

## 한계

아이폰 HEIC는 브라우저가 열지 못해서 처리할 수 없다. JPG로 바꿔서 넣어야 한다. 동영상은 대상이 아니다.
